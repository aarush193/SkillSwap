# SkillSwap

SkillSwap is a full-stack skill exchange platform where users can offer skills, learn from others, and earn or spend time credits through a community-driven time banking system.

## Features

- User Authentication (Supabase Auth)
- User Profiles
- Skill Listings
- Time Banking System
- Dashboard
- Search & Filtering
- AI Integration (Genkit)

## Tech Stack

- Next.js 15
- React
- TypeScript
- Supabase
- PostgreSQL
- Tailwind CSS
- Radix UI
- Genkit AI

## Getting Started

Clone the repository

```bash
npm install
```

Create a `.env.local` file using `.env.local.example`.

Run the development server

```bash
npm run dev
```

Open:

```
http://localhost:9002
```

## Environment Variables

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```
